## AI聊天室

项目描述：此项目要求实现一个 C/S 形式的聊天服务器，普通用户能够注册账号，设置昵称，和服务器的AI聊天；服务器接受客户端请求并响应；管理员用户能够进行账号管理、在线状态以及封禁帐号

项目功能：

- 客户端能够通过邮箱注册账号，设置用户昵称，注册的用户以唯一ID进行标识，密码传到服务器时应当加密处理
- 登录成功后，用户能够和服务器设置的AI服务进行聊天，支持在服务器上同步保存/清除聊天记录
- 服务端处理客户端的请求并正确作出响应
- 服务端能够支持大量的并发连接，以及高负载情况下的可靠性
- C/S 间应用可靠的加密通信，以及良好的拥塞控制和传输可靠性
- 数据存放于合适的数据库
- 一个邮箱只能注册一个账号，注册时应通过验证码进行验证
- 前端使用HTML实现，可使用合适的前端框架
- 主要开发语言为C++
